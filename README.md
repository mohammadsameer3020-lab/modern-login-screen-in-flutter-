## ✨ المميزات (Features)
- **Custom UI Components**: استخدام الـ Widgets المخصصة مثل `CustomTextField` و `CustomContainer` لتنظيم الكود.
- **Google Fonts Integration**: استخدام خط **Rubik** لإعطاء مظهر عصري للنصوص.
- **Responsive Design**: استخدام `SingleChildScrollView` و `Gap` لضمان ظهور الواجهة بشكل سليم على جميع الأحجام.
- **Smooth Navigation**: التنقل بين شاشتي تسجيل الدخول والاشتراك باستخدام `GestureDetector`.

## 🛠️ التقنيات والمكتبات (Tech Stack)
- **Framework**: Flutter (Dart)
- **Fonts**: `google_fonts`
- **Layout**: `gap` لمسافات دقيقة بين العناصر.
- **Assets**: استخدام صور مخصصة للخلفية والشعارات.

## 📂 هيكلة الكود (Code Structure)
يحتوي المشروع على تنظيم للمجلدات لسهولة الصيانة:
- `lib/Screen/`: تحتوي على شاشات التطبيق (`SignInScreen`, `SignUpScreen`).
- `lib/widgets/`: تحتوي على العناصر المخصصة والقابلة لإعادة الاستخدام.
